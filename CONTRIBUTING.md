# Help improve this project

You do not need to be a programmer to help. Try the setup, tell us which computer and Ubuntu version you used, and point out any instructions that were confusing.

For a problem report, tell us what you tried, what you expected, and what actually happened. Mention whether you used the window, Bash, or Codex. Leave out private speech, transcripts, passwords, and account details.

For a change, keep it focused and explain the benefit in ordinary language. Run the checks in [Testing](tests/README.md) and say which real-world behavior you tested. Do not claim that a simulated check proves a shortcut works on every desktop.

Please keep the README welcoming to people who are not programmers. Product suggestions should explain why the item is useful and whether it has actually been tested.
